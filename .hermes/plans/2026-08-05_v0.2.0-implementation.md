# v0.2.0 Implementation Plan

> **Goal:** Ship v0.2.0 with working converters, completed runners, and a generic config system.

**Architecture:** Build from the core outward — first fill gaps in `momus-core` (config, schema validation, dependency resolution, report output), then implement the highest-value converters (cURL, HAR), then complete the scaffolded runners (bench, fuzz, contract), and finally port the FHIR converter from fhir-autotest.

**Tech Stack:** Rust edition 2024, anyhow, serde, reqwest, tokio, axum, jsonschema, petgraph

---

## Task List (ordered by dependency)

### Phase 1: Core Foundation

- **Task 1:** Add generic TOML config system to `momus-core`
- **Task 2:** Wire in JSON Schema validation (jsonschema crate)
- **Task 3:** Add generic dependency resolver (topological sort)
- **Task 4:** Add JSON file output for RunReport
- **Task 5:** Add `{env.VAR}` template syntax

### Phase 2: Converters

- **Task 6:** Implement cURL converter (parse → TestPlan)
- **Task 7:** Implement HAR converter (parse → TestPlan)

### Phase 3: Mock Server Enhancement

- **Task 8:** Add stateful CRUD store to `momus-mock` (port from fhir-autotest)

### Phase 4: Runner Implementations

- **Task 9:** Implement `momus-bench` steady mode runner
- **Task 10:** Implement `momus-fuzz` runner (wire mutators to HTTP)
- **Task 11:** Implement `momus-contract` profile validation (port from fhir-autotest)

### Phase 5: FHIR Converter (port from fhir-autotest)

- **Task 12:** Port FHIR model types (StructureDefinition, CapabilityStatement, etc.)
- **Task 13:** Port IG package parser (.tgz)
- **Task 14:** Port profile resolver (parent chain, registry download)
- **Task 15:** Port resource generator (5-pass)
- **Task 16:** Port test plan generator
- **Task 17:** Port orchestrator and executor
- **Task 18:** Port response assertions and validator
