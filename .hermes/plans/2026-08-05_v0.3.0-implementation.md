# v0.3.0 Implementation Plan

> **Goal:** Ship v0.3.0 with OpenAPI/Postman converters, FHIR profile resolver, bulk data, and advanced FHIR test generation.

**Architecture:** Build from the highest-value items first — OpenAPI converter unlocks the most utility, then FHIR profile resolver and bulk data complete the FHIR pipeline, then Postman and GraphQL converters.

---

## Task List

### Phase 1: OpenAPI Converter (highest value)

- **Task 1:** Add OpenAPI spec parsing dependency (`openapiv3` crate)
- **Task 2:** Implement OpenAPI → TestPlan converter (paths, operations, schemas, parameters, security)
- **Task 3:** Generate example request bodies from schemas
- **Task 4:** Generate Schema assertions from response schemas

### Phase 2: FHIR Profile Resolver

- **Task 5:** Port profile resolver (parent chain resolution, FHIR registry download)
- **Task 6:** Port value set resolution (ValueSet → system maps, CodeSystem first-code maps)
- **Task 7:** Add near/proximity search test generation
- **Task 8:** Add chained search test generation
- **Task 9:** Add conformance tests (mustSupport field presence)

### Phase 3: FHIR Bulk Data

- **Task 10:** Port bulk data generator (NDJSON with cross-references)
- **Task 11:** Port bulk loader (concurrent NDJSON upload with wave ordering)
- **Task 12:** Port HCPD/AU-specific generation

### Phase 4: Postman & GraphQL Converters

- **Task 13:** Implement Postman Collection v2.1 converter
- **Task 14:** Implement GraphQL SDL converter

### Phase 5: Core Enhancements

- **Task 15:** Implement ResponseTime assertion
- **Task 16:** Add HTML report output for bench/run
- **Task 17:** Implement chaos ConnectionReset, PacketLoss, ClockSkew experiments
