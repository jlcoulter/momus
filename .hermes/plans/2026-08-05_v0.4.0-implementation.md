# v0.4.0 Implementation Plan

> **Goal:** Ship v0.4.0 with multi-protocol support via TransportAdapter trait, gRPC converter, script execution, and full JSONPath.

**Architecture:** Build from the foundation up — TransportAdapter trait first (decouples engine from HTTP), then gRPC converter, then script execution, then full JSONPath.

---

## Task List

### Phase 1: TransportAdapter Trait

- **Task 1:** Define `TransportAdapter` trait in `momus-core` with `send_request()` method
- **Task 2:** Implement `HttpAdapter` (current reqwest-based transport)
- **Task 3:** Refactor `runner.rs` to use `TransportAdapter` instead of direct reqwest calls
- **Task 4:** Update `RunContext` to accept generic transport

### Phase 2: gRPC Converter

- **Task 5:** Add `tonic` and `prost` dependencies to `momus-convert`
- **Task 6:** Implement gRPC proto file parser (basic reflection-based)
- **Task 7:** Implement `GrpcAdapter` using tonic client
- **Task 8:** Wire gRPC into the CLI

### Phase 3: Script Step Execution

- **Task 9:** Add `rhai` dependency to `momus-core`
- **Task 10:** Implement script execution engine
- **Task 11:** Wire script steps into the runner

### Phase 4: Full JSONPath Support

- **Task 12:** Add `jsonpath-rust` dependency
- **Task 13:** Replace simple JSONPath resolver with full implementation

### Phase 5: Core Enhancements

- **Task 14:** Update FEATURES.md and DESIGN.md
- **Task 15:** Bump version to 0.4.0

## Verification

After each task:
```bash
cargo test --all-targets
cargo clippy --all-targets -- -D warnings
cargo fmt --check
git commit
```
